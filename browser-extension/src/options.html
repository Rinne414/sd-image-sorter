SD Image Sorter

Save pictures from any web page into SD Image Sorter, with the page they came from.

Connection

Only an address on this computer (127.0.0.1 or localhost) is accepted.

Pairing

The program asks "Allow this browser extension?" in its own window. Until you allow it there, nothing can be saved.

Access to web pages

The browser has not given this extension access to web pages, so it cannot read pictures or reach the program.

Saving

Right-click a picture and choose "Save to SD Image Sorter", or "Save pictures on this page..." to pick several. Pictures go to the program's output folder, collected/date, and appear in the gallery.
